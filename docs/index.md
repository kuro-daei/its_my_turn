「今日から私は。Claude Code 編」は、プログラミング経験がない方でも Claude Code を使いこなせるようになることを目指したハンズオン形式の入門カリキュラムです。

## 対象者

- PC 操作に慣れた非エンジニア（PM・デザイナー・ビジネス職など）
- Claude Code に興味はあるけど、何から始めればいいかわからない方
- ターミナルを少し使えるくらいの方
