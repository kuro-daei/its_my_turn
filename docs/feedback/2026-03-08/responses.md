### 回答3

**①きっかけ・期待**
Claude Code をローカル（WSL じゃない）でエディタ上で触っていましたが、なんだか X 界隈で見るのとは違うな？と勉強不足な部分があると感じていたので、その違和感を知れるのでは？と思って違和感探しで参加しました。

**②期待通り**
上記の違和感を発見できたこと。例えば、一気にインストールするなどは CLI の方がやりやすく、多くのプラグインが既にあって一気にインストールできる体験は CLI ならではだと感じました。

**③期待以上**
WSL を実際に触ってみることで、なんでローカルじゃないの？を深ぼるキッカケになり、今は WSL で操作してます。（Mac へ同じ環境を移行しやすかったです）

あとは、昔から？？でスルーしていたワードや方法が所々に出てきて、地味ですが長年の謎が溶けて良かったです。ターミナル上でカーソルの位置より前を削除する、コピペ、モード変更など、当たり前の操作がためになりました笑

おかげさまで今は Claude Code をカスタマイズしながら、自分の環境を構築中していけてます。また、TODO アプリを作る練習をしてみます！

**④期待以下**
満たなかったことはなく知識不足の部分ですが、ツールが複数出てくると、何がどう連動しているのか、何が変わったら他のツールが影響して動いて結果どうなるのか？が後半は理解しきれずでした。。。

具体的には GitHub までは理解できますが、ローカル→GitHub→DB でその間に認証がーというのがそれぞれに発生する部分は Terminal だけではイメージが付いてこなかった感じです。
