## ターミナルとは何か

### GUI と CUI の違い

普段 PC を操作するとき、アイコンをクリックしたりメニューを選んだりしますよね。これを **GUI（グイ）** と呼びます。Graphical User Interface の略で、「グラフィック（画像・アイコン）で操作するインターフェース」という意味です。

一方、ターミナルは **CUI（シーユーアイ）** という操作方式です。Character User Interface の略で、「文字（コマンド）を入力して操作する」方式です。

たとえ話をすると、

- **GUI** = カフェのタブレット注文端末。ドリンクの写真をタップして選ぶ
- **CUI** = カフェのカウンター。「ラテ、Lサイズ、砂糖なしで」と口頭で伝える

口頭注文（CUI）は最初は慣れないかもしれませんが、慣れると素早くて自由度が高いです。プログラムの実行や複数のファイル操作など、GUI では数十回クリックが必要な操作を、コマンド1行で済ませられることもあります。

### なぜ開発ではターミナルを使うのか

開発ツールの多くは CUI（コマンド）で動くように設計されています。理由は主に以下の通りです。

- **自動化しやすい**: コマンドはスクリプト（命令の羅列）にして繰り返し実行できる
- **再現性が高い**: 「このコマンドを実行した」という記録が残る
- **遠隔操作できる**: サーバー（離れた場所にあるコンピュータ）もコマンドで操作できる

Claude Code 自体もターミナル上で動くツールです。Claude Code を使いこなすために、まずターミナルに慣れておきましょう。

### ターミナルを開く

| OS | 使うアプリ |
|---|---|
| Mac | ターミナル.app（Launchpad → その他 → ターミナル） |
| Windows（WSL） | Ubuntu ターミナル（スタートメニュー → Ubuntu） |

## よく使うコマンド一覧

以下のコマンドをすべて覚える必要はありません。「こういうコマンドがあるんだ」という一覧として参照してください。

| コマンド | 読み方 | 意味 |
|---|---|---|
| `pwd` | ピーダブリュディー | 現在地（カレントディレクトリ）を表示する |
| `ls` | エルエス | 今いるフォルダの中のファイル・フォルダ一覧を表示する |
| `cd フォルダ名` | シーディー | 指定したフォルダに移動する |
| `mkdir フォルダ名` | エムケーディーアイアール | 新しいフォルダを作成する |
| `touch ファイル名` | タッチ | 新しい空のファイルを作成する |
| `cat ファイル名` | キャット | ファイルの中身をターミナルに表示する |
| `cp 元 コピー先` | シーピー | ファイル・フォルダをコピーする |
| `mv 元 移動先` | エムブイ | ファイル・フォルダを移動する／名前を変更する |
| `rm ファイル名` | アールエム | ファイルを削除する（取り消し不可） |

> [!TIP]
> **Tab 補完を活用しよう**: コマンドやファイル名を途中まで入力して `Tab` キーを押すと、自動的に補完してくれます。たとえば `cd ba` まで入力して `Tab` を押すと `cd bash-practice/` のように補完されます。タイプミスを減らせるので積極的に使いましょう。

## パスの概念

### ファイルシステムとは

コンピュータの中のファイル・フォルダは「木」のような階層構造になっています。

```
/（根っこ）
├── Users/
│   └── yourname/（あなたのホーム）
│       ├── Documents/
│       ├── Downloads/
│       └── works/
└── Applications/
```

この「どこにいるか」を示すのが **パス（path）** です。道順を示すので「パス（path = 道）」と呼びます。

### 絶対パスと相対パス

**絶対パス**は、根っこ（`/`）から始まる完全な住所です。

```
/Users/yourname/works/my-project/hello.txt
```

**相対パス**は、今いる場所からの相対的な位置です。

```
works/my-project/hello.txt   （今 /Users/yourname にいる場合）
```

| 記号 | 意味 |
|---|---|
| `/` | 根っこ（ルート）ディレクトリ |
| `~` | ホームディレクトリ（`/Users/yourname` の省略形） |
| `.` | 今いるディレクトリ |
| `..` | 一つ上のディレクトリ |

`~` を使うと、ホームからの絶対パスを短く書けます。`~/works` は `/Users/yourname/works` と同じ意味です。

## ハンズオン：ファイル・フォルダを操作してみよう

実際にターミナルを操作しながら基本コマンドを体験します。コマンドをコピーして実行してみましょう。

### Step 1: ターミナルを開いて現在地を確認する

- [ ] ターミナルアプリを開く
- [ ] 以下のコマンドを入力して `Enter` を押す

```bash
pwd
```

```output
/Users/yourname
```

今いる場所（ホームディレクトリ）が表示されます。

---

### Step 2: ホームに移動してフォルダ一覧を見る

- [ ] ホームディレクトリに移動する

```bash
cd ~
```

- [ ] フォルダ一覧を表示する

```bash
ls
```

```output
Desktop    Documents  Downloads  Movies  Music  Pictures  works
```

`works` フォルダが見えていれば OK です（`~/works` フォルダがない場合は次の Step で作成します）。

---

### Step 3: works フォルダに入る

- [ ] `works` フォルダに移動する

```bash
cd ~/works
```

もし `works` フォルダが存在しない場合は先に作成します。

```bash
mkdir ~/works
cd ~/works
```

---

### Step 4: 練習用フォルダを作る

- [ ] `bash-practice` という名前のフォルダを作成する

```bash
mkdir bash-practice
```

- [ ] フォルダが作成されたか確認する

```bash
ls
```

```output
bash-practice
```

---

### Step 5: 作ったフォルダに入る

- [ ] `bash-practice` フォルダに移動する

```bash
cd bash-practice
```

- [ ] 現在地を確認する

```bash
pwd
```

```output
/Users/yourname/works/bash-practice
```

---

### Step 6: ファイルを作る

- [ ] `hello.txt` というファイルを作成する

```bash
touch hello.txt
```

- [ ] ファイルが作成されたか確認する

```bash
ls
```

```output
hello.txt
```

---

### Step 7: ファイルに文字を書き込んで中身を確認する

`touch` で作ったファイルは空です。`echo` コマンドで文字を書き込んでから中身を確認しましょう。

- [ ] ファイルに文字を書き込む（`>` は「上書き保存」の意味）

```bash
echo "はじめてのターミナル操作" > hello.txt
```

- [ ] ファイルの中身を表示する

```bash
cat hello.txt
```

```output
はじめてのターミナル操作
```

---

### Step 8: 元のフォルダに戻って確認する

- [ ] 一つ上のフォルダ（`works`）に戻る

```bash
cd ..
```

- [ ] 現在地を確認する

```bash
pwd
```

```output
/Users/yourname/works
```

- [ ] `bash-practice` フォルダが見えることを確認する

```bash
ls
```

```output
bash-practice
```

お疲れさまでした。基本的なファイル・フォルダ操作の流れを体験できました。

## こんなときどうする？

### コマンドを間違えた・止まってしまった

`Ctrl + C` を押すと、実行中のコマンドを中断できます。何かおかしいと思ったらまず `Ctrl + C` を試してみましょう。

### どこにいるかわからなくなった

```bash
cd ~
```

`cd ~` を実行するといつでもホームディレクトリに戻れます。迷子になったらここから再スタートしましょう。

> [!WARNING]
> **`rm` コマンドは取り消せません**: `rm` で削除したファイルはゴミ箱に入らず、即座に完全削除されます。特に `rm -rf` は指定したフォルダとその中身をすべて削除する強力なコマンドです。実行前に必ず対象を確認してください。
