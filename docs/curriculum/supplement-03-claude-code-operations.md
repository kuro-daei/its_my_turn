## 1. Claude Code の起動パターン

Claude Code にはいくつかの起動方法があります。**日常の作業では `claude` だけ知っていれば十分**ですが、作業の性質に合わせて使い分けることでより快適になります。

| コマンド | 説明 | 使いどころ |
|---------|------|----------|
| `claude` | 対話型で起動（通常の使い方） | 日常的な作業 |
| `claude -w 名前` | Worktree（別の机）を作って起動 | 機能追加・修正作業（Chapter 5 で使う） |
| `claude --continue` / `claude -c` | 直前のセッションを続ける | 作業を中断して再開するとき |
| `claude --resume` | 過去のセッションを選んで再開 | 特定の作業を選んで再開するとき |
| `claude -p "質問"` | 一問一答モード（対話しない） | 試しに聞くだけのとき |

> **セッションとは？** Claude Code を起動してから終了するまでの 1 回の会話全体のことです。会話の履歴がまるごと保存されており、後から再開することができます。

**たとえ話:** Claude Code の「セッション」は、書き物をするときの「作業ノート」のようなものです。ノートには会話の流れが全部書いてあり、次の日に続きから始めることも、「先週の別のノート」を引っ張り出すこともできます。

### `claude -p` の使い方

```bash
# bash
# 一問一答で聞くだけ（セッションを開かない）
claude -p "Markdown の表の書き方を教えて"
```

「少し調べるだけで、作業はしたくない」というときに便利です。

## 2. セッション管理 — 作業の「続き」を再開する

### `--continue` と `--resume` の使い分け

| コマンド | 動作 | 使うとき |
|---------|------|---------|
| `claude --continue`（`-c`） | 直前のセッションをそのまま再開 | 昨日の作業をすぐ続けたいとき |
| `claude --resume` | 過去のセッション一覧を表示して選ぶ | 「あの作業はどのセッションだっけ」というとき |

```bash
# bash
# 直前のセッションを再開する
claude --continue

# 過去のセッション一覧から選ぶ
claude --resume
```

**たとえ話:** `--continue` は「昨日読んでいた本を、しおりのところから再開する」操作です。`--resume` は「本棚に並んだ本の一覧を眺めて、どれを読むか選ぶ」操作です。

### セッションに名前をつける

Claude Code セッションを起動した後、チャット画面で `/rename` コマンドを使うと、セッションに名前をつけられます。

```plaintext
# claude
/rename Google ログイン実装
```

名前をつけておくと、`--resume` で一覧を表示したときに「どのセッションがどの作業か」がすぐにわかります。

> **ヒント:** 1 日の作業を始めるとき、最初に `/rename` で名前をつけておく習慣をつけると、後から探しやすくなります。

## 3. キーボードショートカット — セッション内の操作

Claude Code のチャット画面（セッション内）で使えるキーボードショートカットです。

### 基本操作

| ショートカット | 動作 |
|--------------|------|
| `Ctrl+C` | 入力または生成中の処理をキャンセルする |
| `Ctrl+D` | Claude Code を終了する |
| `Ctrl+L` | 画面をクリアする（表示をリセット） |
| `Esc` | 現在の入力をキャンセルする |
| `Esc` × 2 回 | コードおよび/または会話を前の状態に復元する |

> **`Ctrl+C` と `Ctrl+D` の違い:** `Ctrl+C` は「今やっていることを止める」で、Claude Code 自体は終了しません。`Ctrl+D` は「Claude Code を閉じる」です。Claude Code が長い処理をしていて止めたいときは `Ctrl+C`、作業が終わって終了するときは `Ctrl+D` を使います。

> **`Ctrl+C` と `Esc` の使い分け:**
>
> - **`Ctrl+C`**（標準割り込み）: 入力中でも AI の生成中でも「今やっていることをキャンセル」します。「Claude が長々と返答しているのを止めたい」というときは `Ctrl+C` を使ってください。
> - **`Esc` 1 回**: 現在の入力をキャンセルします。送信前に「やっぱりこの質問はやめよう」と思ったときに使います。
> - **`Esc` × 2 回（素早く 2 回押す）**: コードおよび会話を前の状態に復元します。Claude が行ったコードへの変更も含めて巻き戻ります。

**たとえ話:** `Ctrl+C` は「非常停止ボタン」で、入力中でも生成中でもいつでも押せます。`Esc` 1 回は「書きかけのメモを丸ごと消す」操作。`Esc` × 2 回は「ゲームのセーブポイントに戻る」——会話もコードの変更もまとめて前の状態に戻します。

### 入力補助

| ショートカット | 動作 |
|--------------|------|
| `Shift+Enter` | 改行して複数行の入力を続ける |
| `↑` / `↓` | 過去に送った入力を呼び出す |

**たとえ話:** `Shift+Enter` は、メッセージアプリで「Shift を押しながら Enter で改行」するのと同じ感覚です。Enter だけで送信されてしまうので、長い指示を書くときに使います。

### モード切り替え

| ショートカット | 動作 |
|--------------|------|
| `Shift+Tab` | 権限モードを切り替える（通常 → 自動承認 → Plan モード → 通常…） |

> **権限モードとは？** Claude Code がファイル操作やコマンド実行などのツールを使うとき、「毎回確認する（通常）」「全部自動で進める（自動承認）」「先に計画だけ立てる（Plan モード）」の 3 段階を切り替えられます。Shift+Tab を押すたびに順番に切り替わります。
>
> - **通常モード**: 何かする前に確認が入る。慎重に進めたいとき
> - **自動承認モード**: 確認なしで全部進む。手順が確立しているとき
> - **Plan モード**: 実行せず計画だけ立てる。「先に何をするか見せて」のとき

### バックグラウンド実行

| ショートカット | 動作 |
|--------------|------|
| `Ctrl+B` | 実行中のコマンドをバックグラウンドに送る |

## 4. スラッシュコマンド — チャット画面の内蔵機能

Claude Code のチャット画面（セッション内）で `/` から始まるコマンドを入力すると、特別な操作ができます。

### よく使うスラッシュコマンド

| コマンド | 動作 |
|---------|------|
| `/clear` | 会話履歴をクリアして新しい会話を始める |
| `/rename 名前` | このセッションに名前をつける |
| `/resume` | 過去のセッション一覧を表示して選ぶ |
| `/compact` | 長くなった会話を圧縮してコンテキストを節約する |
| `/memory` | CLAUDE.md（Claude Code の記憶ファイル）を開いて編集する |
| `/cost` | このセッションで使ったトークン数・コストを確認する |
| `/exit` | Claude Code を終了する |
| `/help` | ヘルプ一覧を表示する |
| `/init` | プロジェクトを初期化して CLAUDE.md を生成する |

> **CLAUDE.md とは？** Claude Code がプロジェクトを理解するための「説明書」ファイルです。「このプロジェクトの目的」「どんなルールで作業するか」などを書いておくと、Claude Code が毎回読み込んで作業に活かします。`/memory` で直接編集できます。

### `/compact` を使うタイミング

Claude Code は長い会話を続けていると、「コンテキスト（一度に記憶できる量）」の上限に近づきます。画面に「コンテキストが少なくなってきた」という表示が出たら、`/compact` を実行してください。

```plaintext
# claude
/compact
```

> **`/compact` の効果:** 長い会話の内容を要約・圧縮して、コンテキストの空き容量を増やします。会話の流れと重要な情報は保持されるので、作業の質を落とさずに続けられます。

**たとえ話:** 机の上に書類が積み上がって作業しにくくなってきたとき、「重要なメモだけ残してあとは片付ける」整理整頓が `/compact` のイメージです。

## 5. Worktree 起動のパターン

`claude -w` コマンドは「新しい机を用意して、その机で Claude Code を起動する」コマンドです。Worktree（机）の詳しい仕組みは補足 2 を参照してください。

```bash
# bash
# 名前なしで起動（ランダムな名前が自動付与される）
claude -w

# 名前をつけて起動（推奨）
claude -w feat_user_auth
```

> **同じ名前で起動した場合:** すでに `feat_user_auth` という名前の Worktree が存在している場合、同じ名前で `claude -w feat_user_auth` を実行すると**新しく作成されず、既存の Worktree が使われます**。これは「途中の作業机に戻る」という操作になります。

### Worktree の名前のつけ方

| パターン | 意味 | 例 |
|---------|------|----|
| `feat_機能名` | 新機能の追加 | `feat_user_auth` |
| `fix_issue_番号` | Issue 対応の修正 | `fix_issue_3` |
| `docs_説明` | ドキュメント修正 | `docs_readme` |

「何のための作業か」が名前からわかるようにすると、後から管理しやすくなります。

## 6. まとめ — よく使う操作を 1 枚で

### 起動のクイックリファレンス

```bash
# bash
# 通常起動
claude

# Worktree（別の机）を作って起動
claude -w feat_user_auth

# 直前の作業を再開
claude --continue

# 過去のセッションを選んで再開
claude --resume
```

### セッション内のよく使うショートカット

| 操作 | キー |
|------|------|
| 入力・生成をキャンセル | `Ctrl+C` |
| 終了 | `Ctrl+D` |
| 画面をクリア | `Ctrl+L` |
| 現在の入力をキャンセル | `Esc` |
| コード・会話を前の状態に復元 | `Esc` × 2 回 |
| 複数行入力 | `Shift+Enter` |
| 権限モード切り替え | `Shift+Tab` |

### セッション内のよく使うスラッシュコマンド

| コマンド | 用途 |
|---------|------|
| `/rename 名前` | セッションに名前をつける |
| `/compact` | 会話を圧縮してコンテキストを節約 |
| `/clear` | 新しい会話を始める |
| `/cost` | 使用コストを確認 |
| `/help` | コマンド一覧を表示 |

> **覚えておきたい一文:** Claude Code を使いこなすための操作はシンプルです。「`claude` で始めて、`/rename` で名前をつけて、`--continue` で続ける」——この 3 つだけ押さえれば、日々の作業は快適に進みます。止めたいときは `Ctrl+C`、入力をキャンセルしたいときは `Esc`、やり直したいときは `Esc` × 2 回と覚えておくと便利です。
