# /doc-review コマンド

`docs/curriculum/` 以下のカリキュラムドキュメントを横断的にレビューします。

## 実行手順

1. **`chief` エージェントで整合性チェックを実行する**
   - 全チャプターを読み、構造・内容・用語の一貫性を確認する
   - 技術的な記述の正確性が疑わしい箇所は「要確認」としてリストアップする

2. **「要確認」箇所を `tech` エージェントで事実確認する**
   - `chief` がリストアップした技術的な記述について、`tech` に正誤確認を依頼する
   - `tech` の回答をもとに「誤り・要修正」「問題なし」を判定する

3. **レポートをまとめて提示する**
   - 整合性の問題（重要度: 高・中・低）
   - 技術的な誤り・要修正箇所
   - 修正方針

## 使い方

引数なしで実行すると全チャプターを対象にします。

```
/review
```

特定のチャプターを対象にする場合は引数で指定します。

```
/review chapter-04
```
